# 대표 코스 추천 정책

## 후보 선정

선택한 도시에 속한 공개 코스 중 앵커와 모든 일정 장소가 활성 상태인 코스만 후보로 사용한다.

## 점수

최종 점수는 100점이며 태그 70점, 동행자 10점, 시간대 10점, 인기도 10점으로 구성한다.

### 태그 점수

코스가 생성되거나 일정이 수정되면 앵커와 모든 일정 장소의 `PlaceTag`로 `CourseTag`를 다시 계산한다. 같은 장소가 앵커와 일정에 함께 있어도 한 번만 계산한다.

`CourseTag 가중치 = 최대 PlaceTag 가중치 × 0.4 + 태그 보유 장소 비율 × 60`을 사용한다. 계산 결과가 30 미만이면 저장하지 않는다. 추천 시에는 이 자동 생성된 `CourseTag`만 확인하고, 각 요청 태그의 가중치를 평균 내어 70점으로 환산한다.

가중치가 50 이상인 태그를 일치 태그로 본다. 선택한 태그가 모두 일치하면 `FULL_MATCH`, 일부만 일치하면 `PARTIAL_MATCH`, 하나도 일치하지 않으면 `POPULAR_FALLBACK`이다.

### 동행자·시간대 점수

코스에 적합 정보가 있고 요청값과 일치하면 각각 10점, 불일치하면 0점이다. 적합 정보가 아직 등록되지 않은 코스는 신규·미정 코스를 과도하게 불이익 주지 않도록 각각 5점을 받는다.

### 인기 점수

`selectionCount / (selectionCount + 20) × 10`을 사용한다. 선택 20회에서 5점이며 선택 수가 늘수록 최대 10점에 완만하게 가까워진다.

## 결과 구성

총점 내림차순으로 정렬하고 같은 점수면 코스 ID 오름차순으로 정렬한다. 서로 다른 앵커를 우선 선택하며 같은 앵커는 최대 2개까지만 허용한다. 조건을 만족하는 후보가 부족하면 5개보다 적게 반환한다.

일치 코스가 5개보다 적으면 도시 인기 코스로 부족한 자리를 채운다. 응답 전체의 상태는 다음과 같다.

- `PERSONALIZED`: 반환 결과가 모두 사용자 태그와 관련 있음
- `MIXED`: 관련 코스와 인기 fallback 코스가 함께 있음
- `POPULAR_FALLBACK`: 관련 코스가 없어 도시 인기 코스만 반환

`MIXED`는 `INSUFFICIENT_TAG_MATCHES`, 완전 fallback은 `NO_TAG_MATCH` 사유를 함께 반환한다. 개별 인기 코스도 `POPULAR_FALLBACK` 매칭 유형을 유지한다.

응답에는 총점, 점수 구성, 일치·불일치 태그, 매칭 유형을 함께 제공해 추천 이유를 확인할 수 있게 한다.

## 현재 한계

- 가중치는 운영 데이터가 쌓이기 전의 초기값이다. 클릭률·선택률 데이터를 근거로 조정해야 한다.
- 코스 생성·수정 API가 추가되면 저장 완료 시 `CourseTagGenerationService`를 호출해야 한다.
- 태그 자동 계산 상수는 초기 시뮬레이션 값이며 실제 선택률 데이터를 근거로 조정해야 한다.
- 후보 코스가 크게 늘면 Java 메모리 계산 대신 DB 후보 축소 또는 사전 계산된 추천 특징값을 검토한다.
