# 서울 지역·태그별 앵커 조사 결과

조사 정리일: **2026-11-07**. 서울 **29개 지역 / 기존 288개 AreaTag / 13개 태그**를 검토했다.

최종 채택은 **346개 고유 앵커, 447개 지역–태그–앵커 연결**이다. 264개 AreaTag에는 채택 앵커가 있고, 나머지24개는 검토했으나 채택 근거가 부족해 보류·제외 기록만 남겼다. 보류는 해당 목적지가 없다는 뜻이 아니다.

## 먼저 볼 파일

- **[지역 → 태그 → 앵커 목록](ANCHORS-BY-AREA.md)**: 요청한 최종 읽기용 결과. 지역 전체 앵커는 중복 제거하고, 태그별 앵커는 한글 이름과 함께 표시한다.
- [최종 검증·지역별 집계·한계](VALIDATION.md): 전체 커버리지, 보류 조합과 검증 범위.
- [anchors.csv](anchors.csv): 앵커명·주소/방문구간·포함관계·이용조건.
- [area_tag_anchors.csv](area_tag_anchors.csv): 어떤 지역의 어떤 태그에 왜 연결됐는지와 출처ID.
- [sources.csv](sources.csv): 실제URL·확인일·짧은 근거 요약·접근 한계와 편향.
- [area_tag_reviews.csv](area_tag_reviews.csv): 채택447건·보류191건·제외5건의 판단 기록.
- [progress.csv](progress.csv): 29개 지역의 검토 상태. `COMPLETED`는 모든 입력 태그를 검토했다는 뜻이며 모든 매장을 전수 조사했다는 뜻은 아니다.
- `areas/{area_code}.md`: 지역별 조사 경과와 **맨 아래 최종 CSV 기준 연결표**. 중간 메모와 최종 상태가 다르면 마지막 표와 CSV가 우선한다.

## 조사 기준

앵커는 해당 태그를 즐기기 위해 실제 방문 목적지로 고를 만한 장소·거리·시장·상권·산책 구간이다. 개별 매장도 가능하지만 모든 업종 매장을 수집하지 않았다. 공식 시설 여부나 규모만으로 결정하지 않고, 국내 나들이·데이트·취향 탐방의 구체적 방문 목적을 확인했다. 기존 Area의 법정동 매핑 안에 있는 주소·경로를 기준으로 판단했다.

장소를 여러 태그에 연결할 때는 같은 ID를 재사용하고 목적을 각각 기록했다. 큰 시설의 내부 공간은 독립 목적이 있을 때만 별도 앵커로 남기고 부모 관계를 기록했다. 개수 할당이나 랭킹·priority 점수는 만들지 않았다.

공식 자료는 위치·운영을, 현장 기사·실제 방문기는 방문 목적을 뒷받침한다. 검색 후 원문 열기를 수행했으며, 원문403·캐시실패 등으로 검색 추출문만 확인한 경우는 출처의 `caveat`에 남겼다. 운영자 선별후기·협찬 취합·플랫폼 편집자료도 한계를 구분했다. 종료된 전시·팝업은 운영 이력이며 현재 행사로 안내하면 안 된다.

세부 요금·주차·당일 영업시간의 반복 검증은 줄였다. 카페·매장 영업, 공연 예매, 전시·팝업 편성과 공원 통제는 실제 방문 시 다시 확인해야 한다.

## 최종 점검

- 29개 지역, 288개 입력 AreaTag 전부 검토 기록 존재. 임의로 새 지역태그를 추가하지 않음.
- ID·관계 중복, 출처 참조, JSON 배열, 부모 관계·순환, 미연결 앵커, 허용 타입, CSV/읽기문서 행 수 검사 통과.
- 최초 계약의 앵커 타입 `VENUE / STREET / DISTRICT / ROUTE`로 통일.
- 석촌호수와 관련 없는 후보 기사를 근거에서 제외하고 올바른 현장 기사로 보완.
- 방이먹자골목 LIVELY는 한 매장 만석 근거만으로 거리 전체를 확정할 수 없어 보류로 정정. 교보천호점도 독립 실제방문 근거가 부족해 보류.
- 좌표 폴리곤 검사, 모든URL의 재접속 검사, 전 매장 망라·실시간 운영 보증은 하지 않음.

지역별 수집 수량 차이가 크다. 초기 두 지역은66개·44개이며 다른 지역은 대체로4~20개다. 탐색 깊이·Area 크기가 함께 반영되어 **앵커 개수를 지역 매력도나 추천 점수로 사용하면 안 된다.** 주요 후보 조사 자료이며 추가 유력 장소가 발견되면 확장할 수 있다.
