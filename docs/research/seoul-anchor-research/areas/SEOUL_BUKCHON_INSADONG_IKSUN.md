# 북촌·인사동·종로 — 조사 진행 중

입력45법정동 기준. 종로1가 교보문고·예지동 광장시장도 이 Area이나 북촌과 단일 짧은 도보권은 아니다.

CAFE: 낙원역, 청수당 익선, 차마시는뜰(차뜰). 국내 실제 주문·동반 방문과 매체·공식 공간 소개를 대조했다. 청수당 상세 도로명과 차뜰 법정동을 추가 대조해야 한다. 전체 태그 검토 완료로 처리하지 않았다. 출처URL·날짜·한계는 sources.csv에 보존했다.

## 위치 보완·쇼핑 후보 추가

- 차마시는뜰: 공식 주소에서 삼청동 확인.
- 청수당: 업체 검색정보 돈화문로11나길31-9·익선동144 대조. 원문 find 한계는 출처 caveat에 기록.
- SHOPPING / 쌈지길: 실제 공예·잡화 탐색과 선물 구매 경험 확인. 상세 공식주소 대조는 후속 확인. 체험 메뉴 판매만으로 WORKSHOP을 자동 부여하지 않았다.

## POPUP 1차 검토

기존 북촌 한옥 팝업권은 여러 브랜드 행사 이력이 있으나 업계 기사·외래관광객 수요가 중심이다. 국내 실제 탐방 근거와 공개 구간을 좁힐 자료가 부족하여 보류했다. KFC·트루동 등 일회 행사를 근거로 별도 공간 앵커를 생성하지 않았다. 자료 부족은 팝업이 없다는 뜻이 아니다. 두 기사 원문에서 확인한 부분과 근거 한계를 sources.csv에 저장했다.

## 서울공예박물관 추가

- EXHIBITION: 실제 전시동 탐방과 작품 촬영 근거.
- WORKSHOP: 보호자가 두 자녀와 예약 후 직접 작품을 만든 참여기 확인. 어린이 대상·보호자 동반·회차 예약 조건을 명시한다.
- 안국동 율곡로3길4로 Area 내부 확인. 시설의 전시·공예마을은 중복 ID로 늘리지 않고 하나의 앵커를 태그별 목적에 연결했다.

## 국립현대미술관 서울

EXHIBITION 앵커로 추가.2026년 직접 현장발권·전시 관람기와 공식 서울관 시설을 대조했다. 특정 무료개방 주간·대기시간은 현재 일반 정책으로 사용하지 않는다. 부속 서점·카페·공연공간은 별도 방문 수요 확인 없이 추가 태그로 연결하지 않았다.

## 광장시장

- MARKET: 국내 필자의 직접 먹자골목·떡볶이 방문 기록.
- SHOPPING: 같은 방문자가2층 수입구제상가에서 운동용 반바지를 구매한 기록을 별도 근거로 사용. 음식 경험만으로 쇼핑을 연결하지 않았다.
- 시장 전체를 단일 앵커로 저장하고 내부 개별점포·카페는 앵커 수로 늘리지 않았다. 예지동·종로5가권이며 북촌과 짧은 단일 도보권으로 안내하지 않는다.

## 공원·공개 골목 산책 보완

- 삼청공원: PARK·WALK. 국내 방문자의 실제 숲 산책·휴식 사진을 근거로 선정. 유아 전용구역은 일반 성인 산책권에서 제외.
- 북촌 한옥마을 공개 골목길: WALK·SCENIC_VIEW. 가회동11·31번지와 삼청동 돌계단을 하나의 경로 앵커로 묶었다. 과거 야간 방문기는 현재 운영근거로 쓰지 않고 서울시 레드존10~17시 방문 제한을 별도 반영.

## 공연·서점 추가 검토

- 서울돈화문국악당: PERFORMANCE. 2022 현장공연·2024 예매관람 두 기록 확인. 과거 행사가 계속 열린다는 의미는 아니다.
- 교보문고 광화문점: BOOKSTORE. 국내 필자의 책 탐색·구매 기록. 종로1가라서 이 Area에 배정했다.
- 북촌전통공예체험관: WORKSHOP 보류. 프로그램과 합산 방문객 수를 한국인 실제 체험 수요로 대체하지 않았다.

## 쇼핑·익선동 골목 방문권

- 안녕인사동 SHOPPING: 실제 층별 상점탐방을 근거로 추가. 개별 입점점포와 호텔은 늘리지 않았다.
- 익선동 한옥거리 TRENDY·WALK: 상업골목의 한옥재해석과 보행 경험으로 선정. 기존 낙원역·청수당과는 개별카페/골목방문권 관계로 이해해야 하며 독립매장 수로 합산하지 않는다.
- 쌈지길 관훈동 주소 확인 보강.
