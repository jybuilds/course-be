
# 대학로·동대문 순차 재검토

입력9태그: CAFE, SHOPPING, EXHIBITION, MARKET, WALK, PARK, PERFORMANCE, BOOKSTORE, SCENIC_VIEW. 경계는 이화동·연건동·충신동·동숭동·혜화동·명륜1~4가·창신동·숭인동. DDP·패션몰 같은 중구 시설은 자동포함하지 않는다.

- CAFE: 학림다방, 국내 필자 반복방문·착석과2026현장사진 확인.
- SHOPPING: 창신동 문구완구거리, 선물구매 목적 재방문·필자 붓구매 확인.
- BOOKSTORE: 동양서림, 직접 책방탐방 및2026운영사진. 위트앤시니컬은 별도후보로 남김.

아직9태그 전체 검토를 마친 상태가 아니다.

## 산책·공원·경관·전시

- 낙산공원·종로측 성곽길: WALK·SCENIC_VIEW. 성북측 자동확장과 전망포인트별 중복을 피했다. PARK는 별도 휴식목적 근거 보완 전 보류.
- 이화벽화마을 공개골목: WALK. 사유지·폐쇄계단은 포함하지 않는다.
- 마로니에공원: PARK. 공원 실제방문·가로수 공원경험. 공연은 장소존재만으로 연결하지 않는다.
- 아르코미술관: EXHIBITION. 현장기사 전시장 내부사진 확인.

## 공연 앵커

- 아르코예술극장: 현대무용 실제 관람기.
- 대학로예술극장: 연극 실제 관람·국내 관객 반응 기사.
- 두 시설은 운영기관이 같아도 별도 주소·독립 공연장으로 저장하며 대소극장별로 숫자를 늘리지 않는다. 동적 공식일정 상세는 검색보조 수준이라는 한계를 출처에 기록했다.

## 동묘 방문권

동묘 벼룩시장·구제상점가를 하나의 앵커로 저장했다. MARKET은 좌판·흥정·시장경험, SHOPPING은 고정 의류·음반상점과 실제 가방구매를 근거로 각각 연결했다. 황학동·신설동까지 동일 Area로 확장하지 않는다.
