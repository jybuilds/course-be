
# 마포 순차조사 시작

도화·공덕·대흥·염리·성산·상암 등을 포함하는 서비스Area. 프릳츠도화 CAFE, 한국영화박물관 EXHIBITION 채택. 책방밀물은 직접 도서구매 증거가 있으나 현재주소 확인중. 하늘공원·평화의공원·경의선숲길·공연·아현시장 순차검토가 남았다.

## 8태그 1차검토 결과

- **CAFE**: 프릳츠 도화점
- **EXHIBITION**: 한국영화박물관
- **MARKET**: 아현시장 — 시장자체 탐방증거 보류
- **WALK**: 경의선숲길 공덕·대흥·신수 구간
- **PARK**: 평화의공원
- **PERFORMANCE**: 마포아트센터
- **BOOKSTORE**: 책방밀물
- **SCENIC_VIEW**: 하늘공원

책방밀물 주소보류는 후속출처로 해결하여 채택. 하늘공원 전망과 평화의공원 정원을 구분하고 연남동 산책로는 제외. 아현시장은 배달구매를 시장방문으로 오인하지 않았다. 주요추가시설 검증 한계는 리뷰CSV 보존.
