
# 상수·합정·망원 조사 시작

기존11태그. 상수·하중·신정·당인·합정·망원동 경계. 홍대 이름이라도 서교동 매장은 앞Area이므로 제외.

- PERFORMANCE: 제비다방·취한제비 — 가까운 무대에서 인디밴드 라이브를 듣기
- MARKET: 망원시장 — 시장 먹거리·생활점포를 구경하는 나들이
- PARK: 망원한강공원 공개 수변 — 강변 녹지에서 쉬며 먹거리와 나들이 즐기기
- WALK: 망원한강공원 공개 수변 — 망원동 한강변 공개 보행로 산책
- SCENIC_VIEW: 망원한강공원 공개 수변 — 한강 수변의 넓은 하늘과 석양 감상
- EXHIBITION: 서울함공원 — 퇴역 함정에 올라 내부 전시·생활시설 관람
- BOOKSTORE: 비플랫폼 — 그림책·소량 아트북의 물성과 제작방식 탐색

CAFE·SHOPPING·WORKSHOP·TRENDY 추가조사 중. 망원정은 기사에서 외부 인지도 부족을 명시하므로 목적지 강도 검토 후 결정. 비플랫폼 워크숍은 편성 소개와 실제 참여 증거를 구분해야 함.

## 11태그 1차 검토 완료

- **CAFE**: 딥블루레이크 커피&로스터스 망원 · 앤트러사이트 합정점
- **SHOPPING**: 제로스페이스 망원
- **EXHIBITION**: 서울함공원
- **MARKET**: 망원시장
- **WALK**: 망원한강공원 공개 수변 · 망원동 망리단길·포은로 골목
- **PARK**: 망원한강공원 공개 수변
- **PERFORMANCE**: 제비다방·취한제비
- **BOOKSTORE**: 비플랫폼
- **WORKSHOP**: 근거 부족 보류 — 비플랫폼 북바인딩
- **TRENDY**: 망원동 망리단길·포은로 골목
- **SCENIC_VIEW**: 망원한강공원 공개 수변

서교동 앤트러사이트는 명칭이 망원으로 소개돼도 제외. WORKSHOP은 편성기사만으로 실제 참여수요를 확정하지 않았다. 유명 추가카페·소품숍의 전수검증 완료를 뜻하지 않는다.
