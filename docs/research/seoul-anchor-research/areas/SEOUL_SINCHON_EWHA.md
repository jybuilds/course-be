# 신촌·이대 — 조사 진행 중

법정동: 북아현·대현·대신·신촌·봉원·창천.

- CAFE: 독수리다방 — 실제 주문·공간 방문기 확인. 추가 후보 조사 중.
- BOOKSTORE: 홍익문고 — 2026년 현장 취재·도서 구매 고객·비밀책 큐레이션 확인.
- WORKSHOP: 연플레이스 신촌점의 창천동 주소와 예약 프로그램 확인. 독립 참여 근거 추가 확인 전 미채택.
- 신촌문화발전소 공식 사이트는 도구 접근 실패. 대체 자료를 조사해야 함.

기타 입력 태그는 아직 완료하지 않았다.

## 추가 확인

- POPUP: 현대백화점 신촌 유플렉스. 여러 층의 교체 팝업 이력과 현장후기 플랫폼 기록을 대조. 종료 행사는 현재 이용 가능 근거가 아니다.
- PERFORMANCE: 유플렉스 앞 스타광장. 여러 그룹 공연·관람객 사진과 정례화 계획 확인. 행사 편성일 방문 조건.
- EXHIBITION: 이대박물관 일반 관람 공식 페이지 확인. 독립 방문 근거는 추가 조사 중.
- WORKSHOP: 솜씨당 클래스 페이지는 본문 추출이 되지 않아 독립 후기 확인을 완료하지 못함.

새 근거는 sources.csv에 URL과 한계를 보존했다.

### 보류
- CAFE / 티앙팡·클로리스 등 추가 카페: 추가 탐방기사 검색에서 이름은 확인했으나 개별 위치·독립 방문근거를 이번에 충분히 대조하지 못함. 일반 카페 전수 수집은 하지 않음.
- CAFE / 연세로·이화여대길 카페권: 개별 목적 카페를 채택. 상권 전체를 커피 탐방 목적으로 독립 방문한다는 근거가 약해 거리 단위 CAFE는 보류.
- SHOPPING / 이화여대길 동측 패션 골목: 기존 관광 소개는 확인되나 과거 전성기와 현재 국내 상품 구매 목적을 구분할 자료가 부족해 보류.
- EXHIBITION / 이화여자대학교박물관: 일반 관람·대현동 위치와 전시 소개는 확인. 옛 기관사진 기반 안내 외 독립 관람 수요 원문 근거가 부족해 보류. 존재·운영 여부가 문제라는 뜻은 아님.
- EXHIBITION / 윤동주기념관: 신촌 역사 도보 방문기에는 등장하나 전시 관람·현행 접근 조건을 독립 확인하지 않아 캠퍼스 산책 구간과 별개 전시 앵커 채택은 보류.
- WALK / 신촌기차역·이화여대길 골목권: 기존 후보 검토. 일반 관광 소개 외 걷는 경험 자체의 실제 방문근거가 부족해 연세로 검증구간으로 제한.
- PERFORMANCE / 신촌문화발전소: 공식 사이트 접근 실패. 기존 공연 후보는 유지하되 현행 공연 편성과 국내 목적 관람 근거를 대조하지 못해 보류.
- PERFORMANCE / 신촌 파랑고래·우드스탁: 문화시설·음악 공간 존재와 과거 이력은 도보 취재에서 확인. 현재 지속 공연 관람 목적을 충분히 검증하지 못함.
- BOOKSTORE / 아크앤북 신촌: 과거 유플렉스12층 방문기와 최근 같은 층 다른 공간 정보가 혼재. 현행 서점 운영을 확정하지 않아 보류.
- WORKSHOP / 연플레이스 신촌점: 창천동 공식 주소·베이킹 과정 확인. 운영자 게시 리뷰 수치와 판매페이지 외 독립 참여 경험 원문을 확보하지 못함. 장소 부재로 판단하지 않음.

### 출처
- [레트로 분위기의 신촌 감성 카페 추천 - 독수리다방](https://standmode.tistory.com/30): 직접 커피를 주문하고 복층 공간·연세로 전망을 체험한 방문기. 연세로36 8층 주소를 명시. 한계: 게시일 미확인. 옛 가격·시간은 재사용하지 않음.
- [70년 신촌 지킨 홍익문고 이야기](https://v.daum.net/v/20260731043244586): 기자가 현장 취재한 신촌 서점. 실제 도서 탐색 고객과 직원 비밀책 큐레이션을 확인. 한계: 직원 독서모임은 일반 방문객 참여 프로그램으로 간주하지 않음.
- [연플레이스 베이킹 공방 신촌점](https://www.yeonplace.com/baking/sinchon): 창천동502-10 신촌로39 3층. 직접 제작·포장하는 베이킹 예약 프로그램과 운영자 게시 리뷰 집계를 확인. 한계: 리뷰100+는 운영자 주장. 독립 참여 후기 검증 전 채택 보류.
- [신촌 현대백화점 팝업 7곳 총정리](https://www.popga.co.kr/content/magazine/465): 유플렉스 연세로13 여러 층에서 캐릭터·게임 콜라보 팝업이 교체 운영되는 구체적 이력과 상품 탐방 목적을 확인. 한계: 행사 안내 기사이며 직접 방문기는 아님. 게시일과 오늘 표기가 하루 어긋남. 종료 행사 현재 안내 금지.
- [슈가슈가룬 팝업](https://prezem.site/places/1537/): 연세로13 팝업의 종료 상태와 현장 후기20 표시를 확인. 한계: 후기 개별 본문은 추출되지 않았다. 표시 수치는 독립 검증 통계가 아니며 반복 운영 보조 근거로만 사용.
- [매주 금요일 신촌 K팝 쇼 열린다 현대백화점 공연 정례화](https://www.newspim.com/news/view/20260922000199): 유플렉스 앞 스타광장의 여러 그룹 시범 공연과 관람객 사진, 정례 공연 계획을 확인. 한계: 백화점 제공 사진·성과 수치에 기초한 기사. 모든 금요일 실제 개최를 보장하지 않음.
- [이화여자대학교박물관 관람 안내](https://museum.ewha.ac.kr/museum/watching/info.do): 이화여대길52 박물관의 일반 관람·전시 운영과 휴관 조건 확인. 한계: 공식 시설 안내만으로 국내 목적 방문 수요가 증명되지는 않음.
- [신촌 레트로 미네르바](https://thing-i-love.com/entry/minerva): 직접 방문해 원두 커피를 주문하고 대부분 좌석이 찬 공간을 경험한 후기. 명물길18 2층 확인. 한계: 2023년 후기이며 당시 가격·영업시간은 재사용하지 않음.
- [미네르바](https://futureheritage.seoul.go.kr/futureHeritageMeet/futureHeritage/view.do?htNo=2531): 창천동13-26 명물길18의 원두커피점, 사이폰 방식과 공간 특성 확인. 한계: 공식 역사 소개는 현행 영업 보증이 아니며 실제 방문 후기와 함께 사용.
- [켜켜이 쌓인 역사와 문화 사이로 신촌 도보여행](https://mediahub.seoul.go.kr/archives/2007939): 해설사와 신촌역 문학의거리·창천문화공원·연세로·연세대 석조건물 구간을 직접 걸은 기록. 한계: 과거 예약 도보 프로그램 일정은 재사용하지 않음. 차량 통제·캠퍼스 출입은 현행 정책 적용.
- [현대백화점의 새 도전 신촌 유플렉스 가보니](https://view.asiae.co.kr/article/2009082321424856136): 기자 현장 방문에서 국내 고객의 의류·신발 구매와 상품 탐색 경험 확인. 한계: 매우 오래된 개점 취재. 당시 입점 브랜드·방문객 규모는 현황으로 사용하지 않음. 2026 팝업 운영자료와 결합.
- [추위도 피하고 문화생활도 즐기고](https://mediahub.seoul.go.kr/archives/185032): 이화여대박물관 복식·미술 전시를 국내 문화생활 목적지로 구체적으로 소개. 한계: 기관 제공 사진 기반 옛 전시 안내. 독립 직접 방문 수요 근거가 약하므로 채택 보류에 사용.
