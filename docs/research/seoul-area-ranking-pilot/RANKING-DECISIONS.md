# 카페·쇼핑·시장 추천 우선순위 v1 — 결정 기록

결정·원문 검토일: 2026-11-03 (Asia/Seoul). 사용자가 승인한 “기본 방문 정책 고정 → 부족 비교 보강 → 전체 순위 산정”을 적용했다. [80개 전체 순위](README.md)와 [순위 CSV](area-tag-rankings-pilot.csv)가 현재 결과다.

**카페 28개·쇼핑 28개·시장 24개에 모두 순위를 부여했다.** 이전 숫자 또는 공란과 비교해 46개 행의 rank 값이 달라졌다. 남았던 쇼핑 순위 보류 두 곳도 배치했다. 태그 부여·가중치·후보 308개와 코드·DB는 이번 단계에서 변경하지 않았다.

## 1. 고정한 기본 정책

특정 브랜드·가격대·원두·식재료 취향이 아직 없는 일반 여가 방문을 기본으로 한다. 태그별로 한 번의 방문 대상으로 고를 만한 지역을 사전에 정렬한다.

1. **그 활동 때문에 일부러 찾아갈 독립 목적과 매력**을 먼저 판단한다. 다른 활동을 하다 들를 수 있다는 이유만으로 독립 목적지와 동일하게 평가하지 않는다.
2. 비슷하면 **고정한 방문권 안의 실제 선택 폭**을 본다. 원거리 다른 거점, 식당 전체, 서점·전시·공원 관객을 해당 태그의 선택 폭으로 더하지 않는다.
3. 그다음 **공간·상품·구경 방식의 차별성**으로 기본 선후를 정한다.

이 정책은 세 정량 점수를 더하거나 태그 가중치를 정렬한 방식이 아니다. 자료로 사실을 확인하고, 가까운 선택지 사이에서는 정책에 따른 편집 판단을 했다. 명동 1위·성수 1위·남대문 1위를 외부 기관의 공식 통계로 주장하지 않는다.

다른 취향일 때 순서가 바뀔 수 있다는 이유로 기본 순위 작성을 계속 보류하지 않는다. 이 기본안과 개인 적합도는 구별한다. 개별 Place 추천이나 다중 태그 조합 점수는 이번에 구현하지 않았다.

### 원거리 합산 방지

- 카페 명동·을지로는 을지로2·3가 골목, 용산은 용리단길, 잠실은 송리단길·석촌호수로, 영등포·문래는 문래를 비교권으로 사용했다.
- 쇼핑 여의도는 더현대를 주 비교권으로, IFC는 별도 대안으로 남겼다. 강서는 김포공항 몰을 주 비교권으로 삼고 마곡 상가를 합산하지 않았다.
- 시장 왕십리·건대는 이번 정책에서 독립 목적이 뚜렷한 마장동 축산시장을 대표 비교권으로 선택했다. 자양시장은 대안이며 두 시장을 한 골목으로 더하지 않았다.
- 시장 청량리는 경동시장을 대표로 삼고 약령시·청량리 시장군의 점포 수를 합산하지 않았다.
- 예전 [핵심 방문권 고정표](CRITERIA-STABILITY.md)는 비교 준비 기록이다. 현재 각 행의 실제 비교권은 전체 순위표를 따른다. 목적 근거가 더 뚜렷한 대표 범위를 선택한 변경이며 Area 경계를 바꾸지 않았다.

## 4. 공동 순위와 취향 비교의 마무리

공동 순위는 두 묶음만 남겼다.

- **SHOPPING 공동 8위: 삼성·코엑스 / 용산.** 각각 한 몰에서 복수 분야 상품을 고르는 독립 목적이 확인된다. 이번 일반 상품 탐방 정책에서는 같은 추천 우선도로 둔다. 매출·브랜드 수가 수학적으로 같다는 주장은 아니다.
- **MARKET 공동 20위: 용산 / 구로·금천.** 용문·별빛남문은 생활 점포·시장 음식 구경이라는 기본 경험을 같은 우선도로 추천한다. 시즌 축제·그날의 대기줄·일회성 혜택은 제외했다.

다른 17건의 취향 비교는 기본 정책으로 선후를 정했다. 예를 들어 성수→연남, 서촌→도산, 한남→연희, 잠실→도산 쇼핑, 동묘→경동 시장 순서다. 특정 취향에서는 역전될 수 있음을 남기되 “취향이 다르다”는 이유로 순위 전체를 미완성으로 두지 않았다.

자료 부족 자체를 동등성의 근거로 삼지 않았다. 현재 두 공동 순위는 이번 편집 정책의 같은 추천 우선도다. 향후 데이터가 생기면 분리할 수 있다.

## 7. 결과 검증과 사용 범위

- 태그 부여 대상과 순위 대상의 집합 일치: CAFE 28 / SHOPPING 28 / MARKET 24.
- 80개 rank가 모두 양의 정수이며 공란·중복 지역–태그 조합 없음.
- 공동 순위는 앞선 지역 수 + 1 방식, 8·8 다음 10 / 20·20 다음 22.
- 전체 표의 현재·이전 순위와 CSV의 지역·이유·출처 일치.
- 이전 비교 29건 모두 resolution과 처리 결과를 기록. 초기 finding은 이력으로 유지.
- 태그 판정·가중치·방문 후보·서비스 Area seed와 애플리케이션 코드·DB 변경 없음.

이 버전은 **세 태그의 기본 추천 우선순위 산정을 완료한 편집 자료**다. 모든 취향에서 통하는 과학적 서열이라고 주장하지 않는다. 나머지 태그의 랭킹, 공동 순위의 점수 변환, 서로 다른 모집단 크기의 정규화, 다중 태그 조합과 실제 코스 동선 검증은 별도 단계다. 이 단계들을 구현했다고 표현하지 않는다.
