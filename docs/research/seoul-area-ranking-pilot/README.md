## 순위를 정한 정책

1. **일부러 찾아갈 독립 목적과 매력**을 먼저 본다.
2. 비슷하면 **고정한 방문권 안의 실제 선택 폭**을 본다. 다른 동네의 점포를 더하지 않는다.
3. 그다음 **공간·상품·구경 방식의 차별성**으로 기본 순서를 정한다.

이 순서는 임의의 숫자 배점이나 정량 측정값이 아니다. 앞뒤가 가까운 지역의 세밀한 차이는 정책에 따른 편집 판단이다. 기존 지역 tag.weight와 인기도·티어·탐색 보정은 순위 산정값에 더하지 않았다. 자료가 적다는 이유로 꼴찌에 넣지 않았다.

공동 순위는 쇼핑 코엑스·용산의 8위, 시장 용문·별빛남문의 20위 두 묶음이다. 같은 정책에서 추천 우선도를 같게 둔 것이며 실측 경쟁력이 같다는 뜻은 아니다. 더 적은 근거만을 이유로 공동 순위를 채우지 않았다. 공동 8위 다음은 10위, 공동 20위 다음은 22위다.
