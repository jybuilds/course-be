> 후속 완료: [추천 우선순위 v1](README.md)과 [결정 기록](RANKING-DECISIONS.md)에서 80개 순위를 모두 산정했다. 아래의 순위 보류·기준 미정 설명은 당시 조사 이력이며 이번 결정이 이를 대체한다.

최신 결과는 [기준 안정화 검토](CRITERIA-STABILITY.md)를 따른다. 아래 내용은 1차 78개 시범의 기록이다. 현재 후보는 80개(숫자 순위 유지 78개·신규 순위 보류 2개)이며, 29개 대표 비교를 통해 취향 차이·추가 근거 필요·조건부 우선·자격 정정을 구분했다.

검토일: 2026-11-03. 범위: CAFE 28개·SHOPPING 26개·MARKET 24개. 최종 정책이나 공식 인기 통계가 아니다.

## 자료 사용 방식

먼저 [29개 Area의 기존 조사](../seoul-area-tagging/README.md)와 지역–태그 판정, 방문 후보를 재검토했다. 지역별 원문 확인 상태·게시일·영업 제한은 해당 지역 보고서에 남아 있다. 이번에 기존 출처 전체를 다시 열어 모든 시설의 운영을 재인증한 것은 아니다.

그 위에 서울 여러 상권을 비교하는 자료를 추가했다. CSV의 source_urls는 각 지역의 방문 근거와 추가 상권 자료다. **출처가 특정 순위를 주장한다는 뜻은 아니다.** checked_at은 이번 비교 검토일이며 원문의 게시일·현장 확인일이 아니다.

## 시범에서 확인된 보완점

1. **일반 쇼핑이라는 말만으로는 충분하지 않다.** 기본 방문자 가정은 유지하되 전체 랭킹 전에 몰·거리·시장 각 유형의 목적 방문성과 대안 선택 폭을 같은 양식으로 비교해야 한다. 유형 자체에 일괄 보너스를 줄 필요는 없다.
2. **조사량이 순위가 되면 안 된다.** 하위권은 지역의 실제 열위보다 기존 자료의 얇음을 반영할 수 있다. 근거가 부족한 인접 비교는 추가 조사하거나 동순위로 보류한다.
3. **큰 Area의 크기 이점을 제한해야 한다.** 하나의 하위 상권만으로도 목적 방문이 성립하는지 먼저 본다. 연희+홍제, 마곡+공항, 천호+고덕, 건대+왕십리를 전부 가까운 동선으로 합산하지 않는다. 다중 태그 추천 단계에서도 서로 먼 하위 상권의 조합을 무조건 균형형으로 판단하면 안 된다.
4. **태그 자격을 먼저 점검해야 한다.** 쇼핑 도봉·노원 등 기존 보류 항목이 정말 미부여가 맞는지 재검토할 필요가 있다. 이번 순위에서 빠졌다는 이유로 열위 지역이라고 결론 내리지 않는다.
5. **정밀한 점수로 바꿀 준비는 아직 아니다.** 공동 순위·순위 간격 처리와 태그별 모집단 크기 보정은 추천 알고리즘 단계에서 별도 검증한다. 이번에 기존 75:25 추천 정책을 수정하거나 새로운 보정치를 더하지 않았다.

따라서 이 시범안으로 **대략적인 상·중·하 비교와 유형 차이는 확인할 수 있지만, 1위부터 마지막까지의 정밀한 우열이 검증됐다고 보기는 어렵다.** 전체 작업의 기준은 목적 방문성·선택 폭·차별성·지속성을 유지하되, 인접 비교 근거와 보류 처리까지 명세에 넣는 것이 적절하다.

## 파일 검증 범위

- 기존 ASSIGN 대상과 정확히 일치하는 CAFE 28행·SHOPPING 26행·MARKET 24행인지 확인.
- city_code·area_code·tag_code, 지역–태그 중복, 비어 있는 이유·출처·검토일 확인.
- 공동 순위를 포함해 앞선 지역 수 + 1 형식이 맞는지 확인.
- README 표의 지역·순위·가중치와 CSV 일치 확인.
- 기존 태깅 CSV의 weight·decision·방문 후보를 수정하지 않음.

## 쇼핑·시장 구분 적용 후 재검토 (2026-11-03)

위 쇼핑 유형 비교 쟁점은 남아 있지만, 시장 먹거리·구경과 상품 쇼핑을 동일한 경험으로 평가하지 않도록 보완했다. [태깅 재검토](../seoul-area-tagging/SHOPPING-MARKET-REVIEW.md) 58개를 먼저 대조한 결과 부여·가중치 변화는 없었고 근거를 구체화했다.

- SHOPPING 26개: 상품·매장 탐색만으로 대조해 시범 순서 유지. 남대문은 품목별 상품 상가, 동묘는 고정 빈티지숍·완구거리로 비교 범위를 명시했다.
- MARKET 24개: 시장 골목·점포·먹거리·특화 경험으로 별도 시범 순위 추가. 쇼핑의 몰·브랜드 강점은 사용하지 않았다.
- CAFE 28개: 기존 CSV 행과 순위·이유·출처 모두 유지. 전체 CSV·README는 이제 78행이다.
- 시장 중하위는 근거가 얇고 유형 차이가 커 공동 순위를 사용했다. 남대문 1위와 광장·망원 등의 순서도 편집 판단이며 실측 인기 순위가 아니다.
- 지역별 보고서·판정 CSV·후보 3개의 혼합 방문 이유·모아보기를 함께 갱신했다. 지역 태그 연결 CSV와 다른 12개 태그 판정은 유지했다.
