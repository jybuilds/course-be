# EXHIBITION — 전시 방문 지역 랭킹

결정·원문 대조일: 2026-11-03. 기존 ASSIGN 28개 지역의 **랭킹·실제 비교 방문권·매력/차별성 키워드를 함께 확정**했다. 순위는 전시 전문가의 작품 품질 심사나 공식 인기 통계가 아니라 일반 문화 관람의 편집 추천 우선순위다.

## 비교 기준

특정 작가·장르·어린이 교육 목적이 아직 지정되지 않은 방문자가 작품·유물·전시 주제를 감상하러 가는 상황을 기본으로 한다. 미술관·박물관·몰 전시를 모두 포함하며 기관 소유 형태나 비싼 입장료를 가산하지 않는다.

1. **관람 자체의 독립 목적**: 작품·유물·주제·해설을 위해 일부러 찾아갈 만한 경험이 무엇인가? 쇼핑·공연·건물 구경 전체를 전시 경험으로 바꾸지 않는다.
2. **고정 방문권의 관람 선택 폭**: 해당 시설·가까운 비교권의 기획·상설 주제를 본다. 원거리 리움·국립중앙박물관, 평창·부암, 쌍문·공릉·중계 등을 합산하지 않는다. 실별 개수나 소장품 수만으로 정렬하지 않는다.
3. **관람 방식의 차별성**: 동시대 미술, 주제별 유물, 산업유산, 화가의 가옥, 몰입형 빛·음악, 예술·기술 실험 등 확인된 경험의 형태를 기록한다.

인접 순위는 이 기본 방문 경험에 따른 편집 판단이다. 낮은 순위가 작품 수준·교육 가치·시설 관리가 나쁘다는 뜻은 아니다. 과학·한의약·군함·영화·특정 작가 취향이 정해지면 해당 전문 목적지를 더 먼저 고를 수 있다. 기존 tag.weight·기관 명성·키워드 수는 계산값으로 쓰지 않았다.

현재 예매 가능 여부와 장기 방문 목적은 분리한다. 며칠간의 행사 준비·교체 공백을 시설의 부재로 보지 않되, 운영하지 않는 전시실·종료 전시를 지금 선택할 수 있다고 더하지 않는다. 실제 코스에서는 아래 운영 조건을 다시 확인해야 한다.

## 대조에서 달라진 범위·운영 판단

- **국립현대미술관 서울:** 방문 안내 하위 화면에는 전시 없음이 표시되지만, 공식 메인은 서울관의 서도호·OLED·올해의 작가상 회차와 소장품을 구분해 안내한다. 따라서 하위 화면의 빈 목록을 서울관 전체 휴관으로 단정하지 않았다. 과천·청주·덕수궁의 프로그램을 서울관에 넣지 않는다.
- **이태원·한남:** 국립중앙박물관의 상설전시·주제별 해설을 이번 대표 비교권으로 선택했다. 리움의 여러 현재 전시도 확인했지만 별도 목적지로 보관하고 합산하지 않았다. Area에 포함되는 서로 먼 기관을 한 산책권으로 포장하지 않는다.
- **한가람미술관:** 본관 1~3층은 2025년10월~2026년12월 예정 공사다. 공식 공지상 정상 운영인 7전시실·한가람디자인미술관·서울서예박물관을 구분했다. 월간 동적 화면의 2020년6월 기본값이나 예전 본관 규모를 현재 편성으로 쓰지 않았다. 달리·Differently·Dali를 살바도르 달리 회고전으로 잘못 소개하지 않는다.
- **문화역서울284:** 11월12~15일 후속 편성과 조사일 임시휴관을 구분한다. 회현 피크닉·현저 역사관을 같은 건물이나 같은 전시 티켓에 포함하지 않는다.
- **성수:** 디뮤지엄의 기존 확인 회차는 종료했고 운영자 동적 페이지 확인 한계가 있어 현재 선택 폭으로 더하지 않았다. 이번 대표권은 본관 유물 전시를 기존에 확인한 수도박물관으로 바꿨다. 성수 팝업의 명성을 가져오지 않는다.
- **노원:** 재단 검색 통합 화면이 아닌 전시 전용 목록에서 노원아트뮤지엄의 협력전과 기간·장소를 확인했다. 박물관 3곳을 합친 자료에서 대표 방문권을 중계로 고정했다. 같은 목록의 다른 갤러리·미정 장소를 더하지 않는다.
- **서촌:** 2024~25년 옛 회차 아래로만 읽으면 현재 전시를 놓친다. 같은 공식 페이지의 2025년9월~2026년12월 회차와 화가의 집·한국화·컬렉션을 대조했다. 야외 작품의 2026년3월 종료 조건은 현재 전시 전체 기간과 구분한다.
- **마포:** 한국영화박물관의 10월28일~11월7일 임시휴관 공지를 확인했다. 지속적인 영화 전시 목적의 순위이지 조사일 즉시 입장 추천이 아니다.
- **여의도:** ALT.1 회차는 11월3일이 마지막 날이다. 독립 관람기에는 전시 구성에 대한 비판도 있다. 호평만 선택하거나 작품 진위에 대한 개인 의견을 확정 사실로 쓰지 않았다.
- 송은은 날짜상 조사 기간에 걸쳐 있으나 화면 구분은 '예정'이라고 남아 있다. 날짜와 상태 라벨을 구분하며 당일 운영 보증으로 쓰지 않는다. 강동 청년 작가 회차·양천 여름 전시·DDP 디자인위크 역시 종료일/예정/지난 전시를 구분한다.

## 상위·인접 비교의 결론

- 북촌·종로와 이태원·한남은 **공동 1위**다. 전자는 서울관의 복수 동시대 미술·소장품, 후자는 국립중앙박물관의 유물·주제 탐구라는 강한 독립 목적이 있다. 취향 미정 기본안에서 같은 추천 우선도로 두었다. 기관의 예산·유물 수·관람 만족도가 같다는 뜻은 아니다. 다음은 3위다.
- 아모레의 작가 기획 → 소마의 미술·조각 경험 → 운영 범위를 제한한 예술의전당 → 송은 → 스페이스K → 뉴미디어 서서울 순서로 기본안을 정했다. 공사 사실을 무시한 예술의전당의 원래 전체 체급을 쓰지 않았다.
- 역사 공간의 기획전(문화역) → 미술관·석파정 결합(부암) → 디자인 공간(DDP) → 시각예술 연구 기획(아르코) → 빛·음악 몰입형(광장) 순서는 일반 관람 탐색의 편집안이다. 공간이 특별하다는 이유만으로 작품 선택 폭을 두 번 가산하지 않았다.
- 작가 가옥·컬렉션(박노수) → 고전 건축·현대미술(남서울) → 자연사 → 유물·공예(이화) → 영화 → 함정 → 한의약은 전문 경험을 구분해 줄 세운 것이다. 서로 다른 전문 분야의 객관적 우열을 증명한 순위라고 해석하지 않는다.
- ALT.1·수도박물관·노원아트뮤지엄·상상마당·술술센터·틈·강동·양천도 각각 독립 관람 목적을 인정한다. 각 행의 이유와 선택권 제한을 함께 읽으며, 자료 수·무료 여부·서울 외곽이라는 이유의 일괄 하위 배치는 하지 않았다.
