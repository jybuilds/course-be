# TRENDY — 힙한 지역 랭킹

판단·원문 대조일: 2026-11-03. 기존 TRENDY ASSIGN **12개 지역의 순위와 방문 매력·차별성 키워드**를 함께 정리했다. 공식 유행 지수나 방문객 수 순위가 아니라, 새로운 취향·브랜드·공간을 발견하려는 여가 목적의 편집 추천 순서다.

## 비교 기준

- **발견할 내용:** 패션·디자인·브랜드·공간의 구체적인 새로움이 있는가? 단순히 젊은 사람이 많거나 새 건물이 있다는 설명과 구분한다.
- **실제 방문권:** 한 골목·인접 상권·한 시설에서 취향을 탐색할 수 있는가? 먼 하위 상권을 더해 상위 Area를 유리하게 하지 않는다.
- **차별성:** 산업 공간 재생, 취향 큐레이션, 거리 스타일, 한옥 재해석처럼 무엇이 다른지 기록한다. 키워드 개수가 점수는 아니다.
- **현재성과 반복성:** 최근 기사·운영자 안내와 기존 조사를 대조한다. 종료된 팝업은 공간의 운영 사례로만 쓰고 현재 체험으로 제시하지 않는다.

상위권은 단순 구매를 넘어 공간·스타일 자체를 탐색할 이유가 선명한 상권을 우선했다. 중위권은 작은 브랜드와 골목 정체성, 하위권은 실내 교체형 콘텐츠와 로컬 체류 대안을 비교했다. 일반적인 첫 탐색의 기본안이며 패션·디저트·레트로·실내 선호에 따라 순서는 달라진다. 순위 간 차이가 통계적으로 유의하다는 뜻은 아니다. 기존 weight·티어·stats·SNS 언급량을 계산값으로 사용하지 않았다. SHOPPING의 상품 선택 폭이나 LIVELY의 북적임과 별도 판단이다.
