# WALK — 산책 방문 지역 랭킹

결정·원문 대조일: 2026-11-03. 기존 WALK ASSIGN **29개 지역 모두의 순위와 방문 매력·차별성 키워드를 함께 확정**했다. 단순 키워드 추가나 기존 가중치 정렬이 아니다. 공식 인기 순위·전수 보행환경 실측이 아닌, 아래 기본 방문 경험의 편집 추천 순서다.

## 비교 기준

정상 등산·장거리 종주가 주목적이 아닌 일반 여가 방문자가 걸으며 동네·문화·자연을 구경하는 상황을 기본으로 한다. 특정 체력·유모차·휠체어 조건은 아직 주어지지 않았다. 따라서 계단이 있는 경로를 전부 배제하지 않되 모든 길을 평탄·무장애라고 표현하지 않는다.

1. **걷기 자체의 목적과 매력**: 구매나 공연 관람을 해야만 즐길 수 있는 것이 아니라, 길을 걸으며 볼 내용이 구체적인가?
2. **고정한 방문권의 경로 선택·연결**: 골목에서 다른 볼거리로 이어지거나 공원 안에서 경로를 고를 수 있는가? 관리구역 전체 길이·면적이나 원거리 상권 수를 더하지 않는다.
3. **경로의 차별성**: 문화 골목·성곽·옛 철길·호수 순환·보행교·생태 수변 등 어떤 방식의 산책인지 기록한다. 공원에서 오래 쉬는 적합성은 PARK, 전망의 매력 자체는 SCENIC_VIEW에서 별도 비교한다.

기본안은 문화·동네 구경의 변화가 있는 경로를 먼저 보고, 자연·수변·공원 내 산책과 비교한다. 역사 취향·평지 선호·야경 선호에 따라 순서가 달라질 수 있다. 이 취향 미정 기본안을 객관적인 산책 품질 지수로 주장하지 않는다. 단일 카페의 조용함·지역 유명세·태그 가중치·키워드 개수는 산책 순위의 계산값이 아니다.

## 가까운 순위의 비교 결정

|비교권|기본 순서와 이유|
|---|---|
|서촌·북촌·석촌·낙산|서촌의 골목–계곡 변화 → 주간 한옥 문화 골목 → 호수 둘레의 완결된 걷기 → 골목–성곽의 변화 순으로 둔다. 북촌 시간제한과 낙산의 계단·경사는 숨기지 않는다. 평지 선호가 주어지면 이 순서 그대로 사용하면 안 된다.|
|공릉·연남|보존 철길을 따라 도시 재생 흔적을 구경하는 공릉 → 선형 녹지에서 골목으로 나가는 연남 순으로 둔다. 전체 숲길의 길이를 해당 Area의 경로 선택 폭으로 쓰지 않는다.|
|여의도·반포·자양|물빛광장–강변 → 수변–섬 연결 → 자양 강변 순으로 둔다. 실제로 확인한 걷기 형태의 편집 선후이며 한강 경관의 계량적 우열은 아니다. 원거리 응봉산·쇼핑시설·계절 축제는 합산하지 않는다.|
|선유도·서울숲·식물원·항동|재생 공원–보행교 → 도시숲 내 길 선택 → 호수원 데크·횡단교 → 정원·저수지 순으로 둔다. 공원 면적·꽃의 수를 순위로 바꾸지 않는다.|
|암사·연희·망원|생태 수변 탐방 경로 → 숲·하천 연결 → 생활 골목·강변 연결 순으로 둔다. 강동의 대표 비교권은 새로 보강한 암사 경로이며 강풀만화거리는 별도 대안이다.|
|서울로·대흥·성북|고가 보행길 → 도심 철길 녹지 → 문화유산 골목 순으로 둔다. 성북은 문화 목적을 인정하되 버스 접근·전체 코스 길이·지형 조건을 생략하지 않는다.|
|묵동·보라매·서서울호수·선정릉|정원·하천 → 공원 내 경로 선택 → 호수·재생 정원 → 역사 숲길 순으로 둔다. 계절 꽃과 입장·개방 조건을 구분한다.|
|노들·용산가족·명동·도산·율현·신촌|개방 수변 → 연못·공원 → 상업거리·공원 자락 → 역사공원 → 정원·수변 → 대학가 골목 순으로 둔다. 모두 걸을 목적은 인정하며, 낮은 순위가 길이 나쁘거나 지역이 쇠퇴했다는 판정은 아니다.|

29개는 1~29 연속 순위다. 미세한 선후는 고정한 기본 방문 목적에 따른 판단이며 계측으로 증명된 점수 차이가 아니다. 같은 Area의 모든 하위 경로를 합쳐 순위를 올리지 않는다.

## 원문 대조에서 반영한 범위·조건

- **북촌:** 공식 레드존 안내는 10~17시 관광객 방문시간을 명시한다. 제한 구역과 주민 생활을 존중하는 주간 공개 구간으로만 기록했다. 익선동 야간 탐방을 북촌에 그대로 옮기지 않는다.
- **서촌·북촌·성북:** 공식 도보 코스에는 2~3시간 안내와 여러 문화 지점이 있다. 이를 짧고 완전 평탄한 산책이라고 바꾸지 않는다. 성북은 공식 문화유산 도보권을 대표로 선택해, 원문 재접근에서 구체 구간을 충분히 읽지 못한 강북 감성길의 ‘전체 평탄함’을 이번 순위 근거로 사용하지 않았다.
- **낙산:** 이화동·성곽 구간을 고정한다. 공연을 예매해야만 걷는 코스가 아니며, 계단·경사 조건을 경로 선택에서 확인한다.
- **경의선숲길:** 시민기자 원문은 차도·개발 구간 때문에 여러 부분으로 나뉜다고 설명한다. 연남과 대흥을 서로 다른 Area의 비교권으로 고정했다. 전체가 하나의 짧고 연속된 길이라는 표현은 쓰지 않는다.
- **공릉:** 관광 코스는 전체 경춘선숲길과 여러 구간을 함께 소개한다. 공릉 구간만 대표로 선택하고 시장·야간 조명정원 전체를 항상 같은 시간에 이용할 수 있다고 묶지 않는다.
- **석촌호수:** 봄 현장 기록의 혼잡·일방통행 통제는 벚꽃철 사례다. 연중 같은 혼잡으로 일반화하지 않는다. 같은 글의 성북천 야장 경험도 송파로 옮기지 않는다. 올림픽공원 공사·스탬프 중단은 다른 경로의 조건으로 유지한다.
- **강동:** 한강 운영자의 고덕·암사 생태체험길에서 암사 탐방로–강변전망데크를 대표 비교권으로 잡았다. 전체 약4km 안내를 짧은 산책으로 바꾸거나 성내 만화거리를 연속 연결하지 않는다. 보호·개방 구간은 방문 시 확인해야 한다.
- **노들섬:** 재개장 현장 글은 공개 수변과 아직 개장하지 않은 정원·공사를 구분한다. 장래 완공 계획을 현재의 경로 선택 폭으로 더하지 않는다.
- **신촌:** 연세로 교통전용지구 해제 공지를 반영해 보행 전용 거리로 보증하지 않는다. 이화여대길·신촌기차역의 구경 목적은 유지한다.
- 장미·벚꽃·분수·축제·생태 프로그램은 계절·회차 조건이다. 강동의 2021년 현장 기록이나 홍대 2025년 걷기 기록을 2026년 실사로 바꾸지 않는다. 일부 공식 URL은 이번 재접근이 시간초과·본문 부족이라 이전 조사에서 읽은 범위와 독립 방문 기록을 유지했으며 새로 원문 전체를 확인했다고 쓰지 않았다.
